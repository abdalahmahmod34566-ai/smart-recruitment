# نظام التوظيف والمقابلات الذكي

تطبيق ويب عربي لإدارة الوظائف والتقديمات بشكل بسيط وواضح.

## المزايا

- نشر الوظائف مع تحديد الخبرة والمهارة المطلوبة.
- استعراض الوظائف والتقديم عليها.
- تقييم تلقائي للمتقدم بناءً على الخبرة والمهارة.
- لوحة ملخص لصاحب العمل لمراجعة الوظائف والطلبات.
- واجهة عربية متجاوبة بالكامل باتجاه RTL.

## التشغيل محليًا

```bash
pnpm install
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/smart-recruitment run dev
```

البيانات الحالية تجريبية ومحفوظة في ذاكرة خادم الـ API، لذلك تعود إلى بيانات البداية عند إعادة تشغيل الخادم.

## البنية

- `artifacts/smart-recruitment` — تطبيق React وVite.
- `artifacts/api-server` — خادم Express وواجهات الوظائف والتقديمات.
- `lib/api-spec/openapi.yaml` — عقد API ومصدر التوليد.
